# 数据集说明（fixtures/）

本目录是**按官方公布信息手工整理的粤港澳大湾区跨境联程班次快照**，用于让规划、仿真与演示跑在真实站名、真实票价量级与真实接驳关系上。它**不是实时数据**，不代表当日实际可售班次。

## 口径

- 采集时间：2025 年公开信息；票价取整到元人民币（`fare_cny`）。
- 港币 / 澳门元票价按近似汇率折算为人民币取整（1 HKD ≈ 0.92 CNY，1 MOP ≈ 0.89 CNY）。
- 高铁 / 城际班次 ID 为演示编号（G/C 开头），时刻与票价对应真实运营区间量级，不对应具体车次号。
- 口岸步行（W 开头）、口岸接驳（ZB/HK/M 开头）为“随到随走”的近似离散化：按固定间隔虚构等效班次，时长为经验值。
- 金巴（JB/JM 开头）按官方公布的高峰 5–15 分钟一班简化为 15 分钟间隔的日间快照。

## 主要来源

- 广深港高铁票价：12306 公布票价（广州南—西九龙二等座 215 元、深圳北—西九龙 75 元、福田—西九龙 68 元；广州南—深圳北 74.5 元取整 75）。
- 港珠澳大桥穿梭巴士（金巴）：香港运输署 / 澳门交通事务局公布，日间 HK$65 / ¥58（珠海侧人民币价），24 小时运营，车程约 40 分钟。
- 广珠城际：12306 公布票价（广州南—珠海二等座 70 元）。
- 蛇口—上环客船：招商邮轮公布票价量级（约 60 元 / 50 分钟，每日数班）。
- 港澳快船：喷射飞航 / 金光飞航公布票价量级（约 175 HKD / 60 分钟）。
- 深圳湾跨境巴士、香港口岸 A 线巴士：运营商公布票价量级。

## 如何更新

替换 `services.csv` / `stations.csv` 后运行 `python -m unittest discover -s tests` 即可校验数据合法性（引用站点存在、票价非负、同日正向行程等由加载器强校验）。也可用环境变量 `TRANSIT_DATA_DIR` 指向另一份数据目录做 A/B 对比。
